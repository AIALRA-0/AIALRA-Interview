题库的诚实拓扑是：

`210 个独立策划的场景锚点 ×（锚点 + 9 个递进练习）= 2,100 个任务`

因此，2,100 不是“2,100 道互不相关的雇主原题”。其中包含 210 个场景锚点、
1,890 个派生训练；派生题分别改变契约、算例、最小实现、故障注入、独立
oracle、规模上限、权衡、事故分析或集成信号。

## 2. 中英双语与内容质量

- 2,100/2,100 题均具有中英双语标题、题干、交付物、评分规则、常见失败、
  追问、参考骨架和可验证完成标准。
- 210/210 锚点具有人工维护的精确中文翻译；795/795 参考骨架条目一一对齐；
  旧通用中文回退为 0。
- 210/210 锚点具有任务专属 oracle；1,512 个技术派生 oracle 和 378 个软技能
  派生 oracle 均逐题唯一。
- 1,512/1,512 个技术派生题在中英文题干中完整携带其场景锚点，使题目脱离生成
  器上下文后仍可作答。
- 168/168 个最小实现练习要求作答者从合法样例构造“恰好违反一个已声明
  不变量”的最小无效样例；题干和 oracle 不再虚构已经提供的坏输入。
- 168/168 个契约练习把原场景标为只读参考，引导候选人只交付契约；冻结锚点
  oracle 只用于评审，不要求候选人先解原题。
- JTAG TAP 锚点及其 9 个派生题共 10/10 均在中英文题干中携带精确 24-edge
  TMS 序列和两条 TDI 序列。
- 130/130 个原子技能拥有直接派生目标覆盖；198 条岗位 → 技能边缺失 0。
- 先修等级倒置、题目先修等级冲突、契约实现冲突、精确重复和相似度
  `>= 0.90` 的近重复均为 0。

独立发布审计复用固定的 `15 个岗位族 × 每族 5 题` 矩阵，75/75 题通过双语
自包含性、可执行性和“题干 → 交付物 → oracle”一致性复核。全部 2,203,950
个题目对也完成中英文近重复穷举，阈值内结果均为 0。详见
[题库质量独立复核](question-bank-quality-audit-v3.md)。

## 4. 可复现构建与运行时完整性

`data/questions.seed.json` 连续三次重新生成的 SHA-256 完全一致：

`a93d82520aca72c50eed147126aacf1b059451ac5156dac865bc74cc3bc25590`

| 产物 | 原始大小 | gzip | Brotli |
| --- | ---: | ---: | ---: |
| 完整源题库 | 18,532,366 B | 2,120,075 B | 499,005 B |
| 浏览器摘要索引 | 2,299,694 B | 191,770 B | 96,854 B |
| 256 个详情分片合计 | 16,337,643 B | 4,478,599 B | 3,570,063 B |
| 最大单个详情分片 | 139,600 B | 28,931 B | 22,281 B |

运行时使用 schema `2.0.0`。SSR 只携带索引和 256 个分片的预期 SHA-256；
浏览器先以 Web Crypto 校验原始响应文本，再解析 JSON。详情按需加载，失败
响应不缓存，公开分片不包含内部 `generationSpec`。

最终 SSR 响应为 734,792 B 原始、125,905 B gzip、99,471 B Brotli，且不包含
题目详情内容。

## 7. 非阻断边界

- 题库仍是 `review-ready`，需要领域专家和真实学习者 pilot 才能校准难度、
  评分一致性和学习收益。
- 组织层是目标宇宙，不表示 529 个节点当前都有开放岗位；本次冻结只有 1 条
  当前职位级证据。正式投递前必须回到具体官方 JD 复核期限、地点、身份、
  出口管制和技能要求。
- 摘要索引为异步 eager load，Brotli 约 96.9 KB；这是使命队列和全局筛选的
  当前产品取舍。
- 一部分公开文档 URL 指向 `latest`、`stable` 或未钉住提交的入口；证据日期
  已冻结，但严格的上游版本钉住仍是后续 P2。
- 本地 `vinext start` 的 Node 兼容性不是本发布的权威运行时；Cloudflare/Sites
  生产构建、部署和浏览器回归才是发布依据。
